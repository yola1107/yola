# 本轮架构重构复盘

日期：2026-10-18。依据本轮实现、失败回归、两轮独立复审、[验收记录](review.md)、Makefile 与本地检查配置。工作流已完成；以下是按优先级排列的环境改进建议，未自动扩大本轮代码范围。

| 优先级 | 本轮证据 | 建议 |
| --- | --- | --- |
| 高 | 已有 `make check` 和 `make race`，但仓库未找到 CI 配置；未配置 hooksPath，`.git/hooks` 只有 sample | 将现有命令接入 CI。check 覆盖两个 module；race 可单独成任务。复用现有入口，避免复制检查脚本 |
| 高 | 环境变量缺失时真实集成会跳过；普通全包检查未覆盖错误的发布 host，真实游戏立即暴露 | 增加专用 Redis/etcd 集成任务，启动前验证依赖和变量，执行本轮小规模分布式与游戏验收；保留大规模容量任务独立运行 |
| 中 | 复审发现 Drain、Register、transport 准备/停止同时迟到的资源交接缺口 | 后续生命周期改动在任务验收中列出“超时后端口可复用、续租停止、迟到资源有 owner”。复用现有行为夹具；组合路径必须观察资源结果 |
| 中 | 1 秒机器人场景在基线和本轮都固定断言三人，而第二机器人尚未入座 | 快速测试先用 Scene RPC 有界等待机器人就绪和动作，再开始短采样。本轮沿用已通过的默认 30 秒；生产调度无需为夹具改动 |
| 低 | 默认 Docker socket 不可用，但已有 Colima；任务可用显式 socket 正常验证 | 环境预检先读取可用 context/socket，只在命令内选定；创建带任务名的临时容器，结束后只清理这些容器 |
| 低 | 跨目录迁移涉及两个 module、Wire 与多个 agent；全量输出易掩盖实际失败 | 派发时固定模型、目录所有权和验收命令；独立 worktree 产出限定 patch。检查写日志，仅回传失败上下文和退出结果 |

规范问题应交给已有 lint：本轮的 error 返回顺序、变量遮蔽均由它捕获并修正。无需向 AGENTS 追加对应规则。领域术语只存 GLOSSARY，长期契约只存架构文档与 ADR，实施证据留在本任务目录。

有效做法是先去掉应用必须知晓的装配配对，再把失败回收集中到唯一所有者。测试围绕 health、RPC、绑定、实际端口与推送结果组织；旧协议测试合并或删除，真实分布式保护继续保留。独立 reviewer 发现后由主 agent 补 RED→GREEN，最后重新检查受影响范围。

本轮没有以行数或文件数判断架构质量。简化收益是应用不再编排 Node 内部就绪与注册、普通服务无需成为 Node、目录身份不会混用。剩余的 epoch、连接代次和排空协议服务于分布式约束；未引入通用 Host、自动房间迁移或恢复框架。

收尾已删除本轮两个临时容器；三个临时 worktree 的任务改动已归档为 `/tmp/yola-self-contained-{node,gateway,sender}-handoff.tar.gz` 后移除。主工作区保留完整集成改动，原有容器与官方底座未动。
