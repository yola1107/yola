# 当前待办与验收条件

本页记录待验收项、触发条件和完成标准。当前实现见[架构契约](./architecture.md)和 [EventBus](./eventbus.md)；实施任务按[本地任务约定](./agents/issue-tracker.md)记录。

## I40 NATS 安全配置

**现状：** 已有凭据、TLS 配置入口和[异步 ACL、重连回归](../event/nats/async_error_test.go)，实际部署尚未联调。

**触发：** 选定 NATS broker、账号、证书和 ACL 后，上线前完成。

**完成：** 用实际配置验证授权与拒绝、异步错误观测、payload 和订阅上限。当前无证据要求新增认证抽象或修改协议。

## I41 和 I45 容量与延迟

**现状：** 原 I41/I45 合并为此项。尚未确定目标负载下的安全容量，历史入座或长尾样本不能直接证明当前框架缺陷。

**触发：** 明确连接数、消息大小与速率、机器、拓扑和 SLO 后执行。

**完成：** 按[性能验证](./performance.md#容量验收)测量登录突发、稳态、慢连接、重连和完整业务，形成对应目标负载的结论。

缺少目标和瓶颈证据时，不增加缓存、队列、并发层或批量 RPC。`test/` 游戏架构不作为根框架重构的前提。

## Redis Cluster 拓扑变更

**现状：** 三主 Cluster 的绑定、epoch、续租和迟到写已有回归记录。三主三从的[槽重分配与切主测试](../locate/redis/cluster_test.go)曾在连续组合时超时，原因未定，不能据此判定生产实现缺陷。

**触发：** 选择 Cluster，且要求扩缩容或切主。使用单机 Redis 的首版不受此项阻塞。

**完成：** 在全新六节点专用集群中重现问题，区分夹具与实现原因，并补齐 RenewNode 的管理场景覆盖。

这里的 Migration 指 Redis 槽重分配，不涉及旧版本数据迁移。
