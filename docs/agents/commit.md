# 提交约定

- 按用户指定范围提交；未指定时优先已有暂存内容，否则仅纳入本任务改动。保留部分暂存边界，范围冲突先澄清。
- 按明确路径暂存已复审内容，执行 `git diff --cached --check` 并验证实际暂存内容；与工作区不同时，在仓库外验证完整候选树。
- 提交前复查分支、HEAD 和暂存区；有冲突或未完成的 Git 操作先停止。提交须原子化，源文件与生成文件一起提交；消息为 `<type>(<scope>): <中文摘要>`，type 使用 `feat|fix|refactor|docs|test|chore`。
- 正常执行 hooks 和签名，不自动改写提交；失败或超时先确认是否已产生提交再重试。提交后核对范围，报告 SHA、验证结果和剩余改动。
